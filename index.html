Rehearse Commit 支持

Rehearse Commit 是一个本地优先的主动学习工具：限时讲解、检查点、Commit 和可选 AI 反馈。

用电脑上的 AI 整理题库

需要手机上的 Rehearse 已提供“外部 AI 连接”（构建 32 及之后，是否可安装以 TestFlight 为准）。下载 Mac 连接器 0.1.0：支持 M 系列芯片、macOS 13.5 或更高，已完成 Apple 签名和公证。无需 Xcode、Node、Python 或手机开发者模式；当前不提供 Intel / Windows 版本。

  1. 解压，把 Rehearse Bridge Setup.app 放到 Mac“应用程序”等固定位置。
  2. 手机与 Mac 连接同一 Wi-Fi。手机进入 Rehearse → 设置 → 外部 AI 连接 → 开启连接，允许本地网络访问。
  3. 在手机复制连接码，打开 Mac 连接器粘贴并连接。连接码代表授权，只交给自己的电脑，不要发到聊天或公开截图。
  4. 选择 Codex、Claude Code 或对应版本的 OpenCode，复制配置，保留已有设置并合并到客户端的 MCP 配置中。Codex 使用 ~/.codex/config.toml；Claude Code 使用当前工作文件夹的 .mcp.json；OpenCode 使用 ~/.config/opencode/opencode.json，请区分 1 / 2 版。
  5. 让 AI 读取题库概况或准备整理方案。需要修改时，回到手机的“待确认修改”，核对后选择“确认应用”或“拒绝这次修改”。

手机保持 Rehearse 在前台，可正常刷题；切到后台或锁屏后暂停，回来恢复。每次连接最长 8 小时，关闭后旧码失效；重新开启或更换网络后重新配对。修改始终需要手机确认，默认只允许删没有 Commit 的题目。AI 可读取题目、答案、Commit、转写与反馈，并交给你选择的模型处理；不开放手机 API Key、原始录音或手机系统操作。

配置说明：Codex · Claude Code · OpenCode。连不上时，先检查同一 Wi-Fi、本地网络权限、手机前台状态与连接码是否过期，再重新配对。

常见问题

麦克风没有声音？
到 iOS 设置 → Rehearse → 麦克风，允许访问。录音只在你主动讲解、语音提问或语音反馈时启用。

讲解转写为空？
到设置 → 本机语音转写，确认已开启并授予语音识别权限。旧录音可以在 Commit 详情里点「重新转写」；中文离线模型和口音会影响准确率。

AI 反馈没有生成？
在设置里配置 OpenAI 兼容接口、模型和 API Key。AI 功能是可选的；未配置时，手动新建、讲解、录音、Commit 和视频仍可正常使用。

删除 App 后 API Key 还在吗？
建议先在设置中移除 API Key，再删除 App。系统钥匙串项不保证随卸载自动清除。

数据存在哪里？
学习数据默认保存在设备上。开启个人 iCloud 题库后，题目、选项、答案和标签会进入本人的私有 iCloud；配置手机 AI 或开启外部 AI 连接后，对应内容会交给你选择的模型或电脑工具处理。详见隐私政策。
