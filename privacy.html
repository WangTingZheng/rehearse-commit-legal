Rehearse Commit 隐私政策

最后更新：2026 年 11 月 9 日

Rehearse Commit 是一个本地优先的主动学习工具。Rehearse Commit 不创建账号，不包含广告、分析 SDK 或自建服务器。

1. 录音与讲解

麦克风只在你主动开始讲解、语音提问或语音反馈时启用。另有设置里的“运行自检”会在已授权时录制约 2 秒的测试音频，用于验证录音和语音检测，完成后删除。录音、激光轨迹、转写、Commit 和讨论默认保存在你的设备上。你可以在 App 中删除单条 Commit 或清除临时录音。

2. 语音识别

本机语音转写使用 Apple Speech 框架的离线识别能力。讲解的自动转写默认关闭，开启时会请求系统语音识别权限；你主动使用语音提问或反馈时，也会使用本机转写并在需要时请求该权限。不支持本机识别时不会回退联网识别。Rehearse Commit 不会把录音发送到开发者服务器。

3. AI 反馈、导入与讨论

AI 功能是可选的，只有当你主动配置并保存 OpenAI 兼容接口和 API Key 后才会发送网络请求：

  • Commit 保存成功后，App 会自动把题目材料、选项、你的选择、检查点、可选转写文本、本轮时长、学习目标及少量此前提交摘要发送到你配置的模型服务，用于生成 AI 反馈，不会再弹出二次确认。
  • 使用 AI 新建单元、从 PDF 导入或从截图导入时，App 会把相应的原文、OCR 文本和补充要求发送到该服务，用于整理题目。
  • 使用全局 AI 教练时，App 会发送题目标题/标签索引、相关题目详情、题组、设置、Commit 标题/日期索引及最近少量详情，以及近期或相关学习回合的目标、进度、提炼和总结。使用“协助修改”时，提案仅在你确认后写入；原始录音和转写不会被模型代写。
  • 使用刷题 Agent 时，App 会发送当前目标、阶段、近期少量可见对话、你亲自提交的提炼，以及按需查询的题目和本轮 Commit（含可用转写、反馈和证据 ID）；可能附带与目标相关且证据仍存在的历史总结。组合选题会发送题目索引及选题约束。真实讲解和 Commit 仍由你完成，不上传录音文件。
  • 使用 AI 同学 PK 时，App 会把当前题目材料、选项、原有答案和模拟水平/误区要求发送到你配置的模型服务，用于生成模拟学生表现；不会把你的本轮讲解或录音作为对手输入。模拟答案可能刻意包含典型错误，不会写回题目答案。朗读使用系统合成声音，不克隆真人。
  • 生成知识地图时，App 会把全部学习单元的标题、标签、检查点与最近结果，以及你选择导入的课程笔记 PDF 提取文本发送到你配置的模型服务，用于生成节点树。录音文件不会上传；地图只在本机保存。
  • 你主动发起反馈讨论或追问时，App 会发送已有反馈、题目上下文、转写文本和你输入的问题。
  • 两个 Agent 的自定义角色提示词保存在本机，随对应 AI 请求发送到你配置的模型服务；恢复默认不会删除学习记录。
  • 未配置模型时不会发送任何 AI 请求；API Key 保存在系统钥匙串，可随时在 App 内移除。

Rehearse Commit 不控制该第三方服务的数据处理方式，请阅读你选择的模型服务隐私政策。录音文件本身不会上传，只有转写文本会随请求发送。

公开联网搜索（可选，默认关闭）

开启设置中的“Agent 联网搜索”后，全局教练或刷题回合可按需查询公开参考链接。搜索服务目前为 360 公开搜索网页，只接收 App 预设的公共主题词及网络连接信息，不接收你的题目、录音、转写、对话原文或 API Key。搜索结果的标题和链接可能随 AI 请求发送到你配置的模型服务。仅取得标题和链接，不代表已读取网页全文或核实结论。关闭开关后不会再发起公开搜索请求；你主动点击外部来源链接则由浏览器访问该网站，适用该网站的隐私政策。

4. 数据收集

开发者不收集、不出售、不共享你的个人数据；没有跨 App 追踪。App 内没有账号系统或云同步。

5. 删除

删除 App 会移除 App 容器内的本机数据；单条 Commit、草稿和录音也可在 App 内删除。保存在系统钥匙串里的 API Key 不保证随 App 卸载自动清除，建议先在设置中移除 Key，再删除 App。

6. 联系与支持

如有隐私问题，请通过 GitHub Issues 联系开发者。常见使用问题见 支持页面。
