Rehearse Commit 隐私政策

最后更新：2026 年 11 月 16 日

Rehearse Commit 是一个本地优先的主动学习工具。Rehearse Commit 不创建账号，不包含广告、分析 SDK 或自建服务器。

1. 录音与讲解

麦克风只在你主动开始讲解、语音提问或语音反馈时启用。另有设置里的“运行自检”会在已授权时录制约 2 秒的测试音频，用于验证录音和语音检测，完成后删除。录音、激光轨迹、转写、Commit 和讨论默认保存在你的设备上。你可以在 App 中删除单条 Commit 或清除临时录音。

2. 语音识别

本机语音转写使用 Apple Speech 框架的离线识别能力。讲解的自动转写默认关闭，开启时会请求系统语音识别权限；你主动使用语音提问或反馈时，也会使用本机转写并在需要时请求该权限。不支持本机识别时不会自动回退联网识别。你也可以另行选择下述云端录音识别；只有你确认上传后，所选录音才会发送给 DeepSeek。Rehearse Commit 不会把录音发送到开发者服务器。

3. AI 反馈、导入与讨论

AI 功能是可选的，只有当你主动配置并保存 OpenAI 兼容接口和 API Key 后才会发送网络请求：

  • Commit 保存成功后，App 会自动把题目材料、选项、你的选择、检查点、可选转写文本、本轮时长、学习目标及少量此前提交摘要发送到你配置的模型服务，用于生成 AI 反馈，不会再弹出二次确认。
  • 使用 AI 新建单元、从 PDF 导入或从截图导入时，App 会把相应的原文、OCR 文本和补充要求发送到该服务，用于整理题目。
  • 使用刷题 Agent 时，App 会发送当前目标、阶段、近期少量可见对话、你亲自提交的提炼，以及按需查询的题目和本轮 Commit（含可用转写、反馈和证据 ID）；可能附带与目标相关且证据仍存在的历史总结。组合选题会发送题目索引及选题约束。真实讲解和 Commit 仍由你完成；刷题 Agent 请求不上传录音文件。
  • 使用 AI 同学 PK 时，App 会把当前题目材料、选项、原有答案和模拟水平/误区要求发送到你配置的模型服务，用于生成模拟学生表现；不会把你的本轮讲解或录音作为对手输入。模拟答案可能刻意包含典型错误，不会写回题目答案。朗读使用系统合成声音，不克隆真人。
  • 生成知识地图时，App 会把全部学习单元的标题、标签、检查点与最近结果，以及你选择导入的课程笔记 PDF 提取文本发送到你配置的模型服务，用于生成节点树。录音文件不会上传；地图只在本机保存。
  • 你主动发起反馈讨论或追问时，App 会发送已有反馈、题目上下文、转写文本和你输入的问题。
  • 刷题 Agent 的自定义角色提示词保存在本机，随对应 AI 请求发送到你配置的模型服务；恢复默认不会删除学习记录。
  • 未配置模型时不会发送任何 AI 请求；API Key 保存在系统钥匙串，可随时在 App 内移除。

Rehearse Commit 不控制第三方服务的数据处理方式，请阅读你选择的模型服务隐私政策。自动反馈、讨论和 Agent 请求只使用可用的转写文本，不上传录音；下面的可选云端识别会在另行确认后上传所选原文件。

云端文件与录音识别（可选）

本机 PDF 提取和本机语音转写仍可使用，不会因失败自动上传。只有你配置的是 DeepSeek 官方服务并主动选择“用云端识别扫描件”或“用云端重新识别”，在确认页数或录音时长、预计费用之后，App 才会把这份 PDF 或这段录音直接发送到 DeepSeek 官方识别接口。自定义模型服务的 Key 不会转发给 DeepSeek；Key 仅用于该服务的身份验证，不写入识别缓存。

云端 PDF 识别每次最多 100 页、25 MiB；云端录音识别每次最多 120 秒，转换后的音频最多 8 MiB，超限不会静默截断。PDF 识别后的文字还会按你选择的导入流程发送给已配置的模型服务整理题目，确认预览后才写入题库。录音识别成功只更新转写，保留原录音、Commit 和已有反馈，不自动重新生成收费的 AI 反馈；如果识别期间原转写改变，会请你选择要保留的版本。

本设备所有 Key 共用每日 0.50 元的识别额度，按刊例价估算，不能代表服务商账单或其他设备的费用，也不包含 AI 整理题目、反馈或讨论费用。请求发送前预留额度，失败或取消后可能仍被服务商计费，因此预留额度不自动退回；App 不自动重试，也不在重启后自动重发未完成请求。

为避免同一文件重复付费，成功识别的文字结果会在本机私有目录缓存，按文件内容、用途及服务凭据的不可逆指纹区分；容量不超过 20 MiB、32 条，缓存有效期为 30 天；过期后不再复用，并在后续使用时清理过期内容。缓存不进入个人 iCloud 题库同步、小组件或设备 iCloud 备份。删除 App 会移除这些本机缓存；删除单条 Commit 不会立即清除独立识别缓存。上传后的文件与结果是否留存、如何删除，适用 DeepSeek 的服务和隐私政策；在 App 内取消、删除记录或移除 Key 不能撤回已发送的数据。

公开联网搜索（可选，默认关闭）

开启设置中的“Agent 联网搜索”后，刷题回合可按需查询公开参考链接。搜索服务目前为 360 公开搜索网页，只接收 App 预设的公共主题词及网络连接信息，不接收你的题目、录音、转写、对话原文或 API Key。搜索结果的标题和链接可能随 AI 请求发送到你配置的模型服务。仅取得标题和链接，不代表已读取网页全文或核实结论。关闭开关后不会再发起公开搜索请求；你主动点击外部来源链接则由浏览器访问该网站，适用该网站的隐私政策。

外部 AI 连接（可选，默认关闭）

你在手机开启连接并把连接码交给自己的电脑后，电脑上的 Codex、Claude Code 或 OpenCode 等工具可通过加密的本地网络连接读取题目、材料、选项、答案、标签及 Commit 中的讲解转写、反馈与学习记录，并可能将这些内容发送给你在电脑选择的 AI 服务。该功能不需要在手机配置模型 Key；不经过开发者服务器，不开放手机操作、API Key、原始录音或笔迹文件。请同时核对所选电脑工具及模型服务的处理和留存政策。

外部 AI 可准备题库修改，但必须由你在手机核对并确认后写入。默认只允许删除没有 Commit 的题目；扩大删除权限需要你本人操作，删除仍需逐次确认。原始讲解、作答和时长不能被模型伪造；补充笔记与原始学习事实分开保存。

连接码包含临时授权信息，请勿公开。电脑连接器将配对信息保存在当前用户的私有本地目录；手机关闭连接会撤销当次连接码，连接最长持续 8 小时。切到后台或锁屏时暂停连接。关闭连接或删除本机配对不能撤回电脑或第三方 AI 已经收到的内容；如需删除，应按所选服务的政策处理。

4. 数据收集

开发者不收集、不出售、不共享你的个人数据；没有跨 App 追踪。App 内没有开发者账号系统。

个人 iCloud 题库同步默认关闭。你在设置中开启后，题目、材料、选项、答案和标签会通过 Apple CloudKit 保存在你自己的私人 iCloud 数据库中，同一 Apple 账号的设备可合并这些内容。录音、视频、Commit、AI 对话、转写和 API Key 不参与此同步。同步使用你的 iCloud 账号与存储空间，不经过开发者服务器。

不同设备同时修改题目时，两个内容版本会保留，副本标为“同步副本”。删除题目只影响当前设备，已删除的题目不会自动再次下载；另一设备及 iCloud 中的副本不会因此删除。关闭同步不删除本机或云端内容。你可在 Apple 的 iCloud 储存空间设置中管理该 App 的云端数据。更换 iCloud 账号后同步会暂停；只有你明确确认，才会将本机题库加入新账号。

5. 删除

删除 App 会移除 App 容器内的本机数据；单条 Commit、草稿和录音也可在 App 内删除。保存在系统钥匙串里的 API Key 不保证随 App 卸载自动清除，建议先在设置中移除 Key，再删除 App。

6. 联系与支持

如有隐私问题，请通过 GitHub Issues 联系开发者。常见使用问题见 支持页面。
